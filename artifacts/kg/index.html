Profitelligence · Knowledge Graph 1.1

A living map of the market.

Profitelligence turns SEC filings — insider trades, fund holdings, corporate events, financials — into a graph an AI agent can walk: ask about a company, hop to its insiders, its biggest holders, what those funds also own, what it earned last quarter. This page shows how it's built. One rule underneath everything: the graph never stores a copy of the data, so its answers can't go stale.

The virtualized pattern (OBDA)THE CORE IDEA

company:NVDA is just an address — there's no stored record behind it. When an agent asks a question about it, a saved query runs right then against the real tables. No sync job, nothing goes stale — the answer is as fresh as the data itself.

The hazard registryENCODED IN THE GRAPH

The gotchas of SEC data that normally live in an analyst's head, written into the graph itself — so the model reads the warning before it makes the mistake. Every traversal that touches one of these returns the warning alongside the numbers.

hazardwhere it bitesthe rule the graph carries
One ID, three kinds of filersidentity resolution The SEC hands the same style of ID to companies, insiders, and funds. The graph always knows which kind it's holding.
Amendments double-countany holdings math Funds re-file corrections; sum naïvely and GE once read 214% of its own shares outstanding. The graph counts each position exactly once.
"Acquired" isn't "bought""insiders are buying" Most acquired shares are grants and option exercises — only ~14% are real open-market buys. The graph keeps the intent code on every transaction so purchases stay separable from paperwork.
Big firms file as many entitiesholder rankings, and any quarter-over-quarter change One household name can be several legal filers. Ownership traversals emit a family token so they can be summed into one firm. On changes, a filer reorganization looks like enormous trading — a fund can appear to exit a position entirely while its sibling entities post it as new. The graph flags this on every change traversal rather than silently averaging it away.
Quarter labels are filing windowstime reasoning A "Q2" holdings filing describes the portfolio as of the end of March. The graph never mistakes filing time for market time.
Tickers driftjoining anything to price Tickers get reused, shared, and listed several at a time. The graph resolves identity through official IDs, not the ticker string.
Accounting tags drift between periodscomparing financials year over year The same line item can be filed under a narrower accounting concept in one period than another — an annual figure tagged as only the domestic or foreign share of the total. The graph returns the concept behind every number so the mismatch is visible, not inferred.
Per-share figures aren't restated for splitsany earnings-per-share trend Filings report what was true at the time. Across a 10-for-1 split, unadjusted earnings per share falls from $5.98 to $0.76 — a collapse that never happened. The graph marks these fields as as-reported and points at the split record.
Cash-flow signs follow the filing, not the labelbuybacks, acquisitions, capital returns A field named for share issuance can hold share repurchases, positive. The graph returns the underlying accounting tag beside the value, so direction is read from the source rather than the column name.
Gifts and grants have no price"did the insider sell high?" A gifted or granted share has no execution price, so any comparison against that day's market price produces nonsense. The graph withholds the price comparison for those transactions instead of reporting a −100% discount.

The bottom four were found by building traversals over data that had never been walked end to end. Making the graph answer questions is also how it audits itself.
