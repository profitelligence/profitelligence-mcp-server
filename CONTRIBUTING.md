# Contributing

Thanks for your interest in the Profitelligence MCP server.

The server runs as a hosted remote service at
`https://mcp.profitelligence.com/mcp`. This repository holds its public
documentation, configuration examples, and MCP registry manifest — there is no
server code to build or run from here.

## How to Contribute

### Report a Problem

Open a [GitHub issue](https://github.com/profitelligence/profitelligence-mcp-server/issues) for:

- Errors or gaps in the tool documentation
- Config examples that do not work with your client
- Connection problems with the hosted endpoint (include your client and its
  version, but never your API key)

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead.

### Improve the Docs

Pull requests that fix or clarify the documentation are welcome:

1. Fork the repository
2. Make your change
3. Open a pull request with a short description of what it fixes

### Request a Feature

Tool and data requests are welcome as GitHub issues. Describe the question you
want your agent to answer; we design tools around questions, not endpoints.

## Code of Conduct

Be respectful, inclusive, and constructive.
